# The trace-quality corpus (issue #341).  One image per line:
#
#   name | category | option sets | magick arguments
#
# corpus.py generate runs "magick ARGUMENTS DIR/NAME.png" for each line.
# Most images are drawn by a command here and need no licence of their own;
# the "outside" ones are files in images/, named as images/NAME.png.
# Option sets are separated by ";"; each set is traced separately, and an
# empty set means autotrace's defaults.  Pairs named NAME and NAME-aa are
# the same drawing without and with anti-aliasing.
#
# Categories: geometry, topology, thin, colour, noise, alpha, centerline,
# outside (stored images from other sources), timing.  Images in "timing"
# get output metrics only, no round trip.
